# CONSUMER COMPLAINT ANALYSIS

## 🔍 BUSINESS PROBLEM
The company lacks clear visibility regarding the number of complaints they are receiving and the count of complaints they are resolving on time. Management doesn't have actual calculations on resolution time, track over monthly trends, or Year-over-Year (YoY) performance graph. Furthermore, the support team operates with limited bandwidth, making it impossible to handle every issue at once. The company needs to analyze the data so the team can identify the companies with the highest number of complaints, pinpoint the most common issues, and determine which high-risk complaints must be taken care of on priority.

---


## 🎯 OBJECTIVE
* To calculate complaint resolution times, track average closure delays, and number of complaints resolved on time.
* To pinpoint the companies with the highest number of complaints, most common issues, and the states with the highest complaint volumes.
* To track monthly volume trends and measure Year-over-Year (YoY) changes in both complaint numbers and average resolution times.
* To build a priority scoring framework to help the customer support team identify and handle high-risk complaints first.
* To build an interactive dashboard for exploring complaint trends and operational performance.

---

## 🛠️ TOOLS USED
* Microsoft Excel
* Power BI

---

## 📁 DATASET DESCRIPTION
The dataset contains customer complaint information for different companies. It includes:
* Unique complaint ID
* Issue raised
* Company name
* Submission channel
* Date the complaint was received
* Date it was resolved
* Whether it was resolved on time
* Whether the consumer disputed the resolution

---

## 📊 DATA PREPARATION USING EXCEL
* Combined and organized the data from Excel spreadsheets.
* Used `XLOOKUP` to map state codes to state names.
* Created additional columns such as Resolution days, Month, and Year for analysis.
* Answered the business questions using Excel and created an interactive dashboard in Power BI.

---

## 📈 POWER BI ANALYSIS
* KPIs indicating total complaints, timely resolution, and average resolution days.
* Analysis of issues that need to be addressed on priority.
* Analysis of average resolution days by year.
* Analysis of top products based on complaint percentage.
* Geographic analysis of complaints by state using Geo Map.
* Year-over-year complaint analysis using a Waterfall Chart.
* Interactive filtering using slicers.
